# เว็บแอป (PWA) และภาพตัวอย่างลิงก์ — คู่มือสั้น

## สิ่งที่ทำอยู่
- **ติดตั้งลงหน้าจอหลัก** — การ์ดอยู่ที่หน้า `#/install` (และหน้าโปรไฟล์ถ้าเพิ่มบรรทัดตามคู่มือ)
- **เปิดแอปได้เมื่อไม่มีอินเทอร์เน็ต** — เก็บเฉพาะไฟล์ของแอป (JS/CSS/ไอคอน) และไฟล์แผนที่ที่เคยเปิดดู
  **ไม่เก็บข้อมูลส่วนตัว** (ทริป งบ ความทรงจำ รูปส่วนตัว ลิงก์แชร์) ข้อมูลเหล่านี้ยังต้องใช้อินเทอร์เน็ตเสมอ
- **อัปเดต** — เมื่อมีเวอร์ชันใหม่จะขึ้นแถบ "มีเวอร์ชันใหม่" ให้กดเอง ไม่สลับเองกลางใช้งาน
- **ภาพตัวอย่างลิงก์** ใน LINE / Facebook — แท็ก Open Graph ถูกใส่ใน `index.html` ตอน Build
- **ไม่ให้ Google เก็บเว็บ** (`noindex`)

## ภาพตัวอย่างลิงก์ (OG)
1. เตรียมภาพ **1200×630** (หรือสัดส่วน 16:9) เป็น **JPG** ขนาดไม่เกิน ~1 MB (squoosh.app ย่อให้ได้) ไม่ควรมีตัวหนังสือในภาพ
2. ตั้งชื่อ `og.jpg` แล้ว Upload ไปที่โฟลเดอร์ `public/img/` ใน GitHub → Commit
3. ถ้าไม่มี `og.jpg` เว็บใช้ `og-default.png` (ภาพมาตรฐาน)
4. LINE/Facebook **เก็บภาพตัวอย่างไว้เป็นวัน** เปลี่ยนภาพแล้วอาจเห็นของเก่าสักพัก ล้างได้ที่ https://developers.facebook.com/tools/debug/ (Facebook) — ของ LINE ต้องรอ
5. ลิงก์แชร์ทริป (`#/s/…`) จะได้ภาพตัวอย่างของทั้งเว็บเสมอ เพราะส่วนหลัง `#` ไม่ถูกส่งไปที่เซิร์ฟเวอร์

## ถ้าเว็บค้างเก่า / มีบั๊กจาก Service Worker
**ระดับ 1 (ผู้ใช้ทำเอง):** หน้า `#/install` → "หน้าเว็บค้างเก่า? ล้างแคชของแอป" (ไม่ลบข้อมูลของผู้ใช้ ไม่ออกจากระบบ)

**ระดับ 2 (สวิตช์ฉุกเฉิน — ทุกเครื่อง):**
1. GitHub → เปิดไฟล์ `pwa.config.json` → ✏️ แก้ `"enabled": true` เป็น `"enabled": false` → Commit
2. รอ Actions ขึ้น ✅ — ทุกเครื่องที่เคยเปิดเว็บจะ "ถอด" Service Worker และล้างแคชของแอปเองตอนเปิดเว็บครั้งถัดไป (ข้อมูลผู้ใช้ไม่ถูกลบ)
3. แก้ปัญหาแล้วเปลี่ยนกลับเป็น `true`

ตัวตรวจ Build จะแสดงคำเตือนทุกครั้งที่สวิตช์ปิดอยู่

## ทดสอบด้วยมือหลัง Deploy
| อุปกรณ์ | ทดสอบ | ผลที่ควรได้ |
|---|---|---|
| Android Chrome | เปิดเว็บ → หน้า `#/install` → "ติดตั้งแอป" | ได้ไอคอนบนหน้าจอหลัก เปิดแล้วเต็มจอ |
| iPhone Safari | หน้า `#/install` → ทำตามขั้นตอน Share → Add to Home Screen | ได้ไอคอน เปิดเป็นแอป (ต้อง Login ใหม่ในแอป) |
| ทุกเครื่อง | เปิดเว็บ 1 ครั้ง รอสักครู่ → ปิดอินเทอร์เน็ต → เปิดแอปใหม่ | แอปเปิดได้ ขึ้นแถบ "ออฟไลน์อยู่" ส่วนที่ต้องใช้ข้อมูลขึ้นข้อความผิดพลาดตามปกติ |
| ทุกเครื่อง | Deploy ใหม่ แล้วเปิดเว็บที่เปิดค้างไว้ | ขึ้นแถบ "มีเวอร์ชันใหม่" กดแล้วโหลดใหม่ 1 ครั้ง |
| LINE | ส่งลิงก์เว็บเข้าแชท | เห็นการ์ดภาพตัวอย่าง (ถ้าไม่ขึ้นทันที ลองลิงก์ใหม่หรือรอสักครู่) |
