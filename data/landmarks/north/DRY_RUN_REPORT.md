## สถานะ Preview ใหม่

ครบทั้ง 16 แถว:

- `id` ว่าง — ไม่มี UUID ปลอม
- `verification=pending`
- `is_demo=no`
- `is_published=no`
- `lat`, `lng`, `google_maps_url` ว่าง
- หมวด 7 slug (`temple`, `national-park`, `nature`, `culture`, `community`, `cave`, `dam`) พบว่ามีใช้ใน Export แต่ Export ไม่มี `is_active` จึงยังยืนยัน active category ไม่ได้

พิกัด Candidate ดอยตุง `20.267451, 99.801423` ยังคงอยู่เฉพาะ `northern_landmark_metadata_pending.csv` และไม่ส่งเข้า places importer เพราะยังรอ Admin ยืนยันว่าเป็นจุดทางเข้า/ศูนย์บริการที่ต้องการ

## ช่องว่างที่ยังปิดไม่ได้

1. **Active categories:** Export มี slug แต่ไม่มีคอลัมน์ `is_active`; ต้องตรวจหน้า Admin Categories หรือ export category ที่มี `slug,is_active`
2. **Schema เริ่มต้น:** repository ยังไม่มี `20261117000001_init_schema.sql`, `…000002_rls.sql`, `…000003_storage.sql` และ `supabase/seed.sql` ตาม README จึงตรวจ constraint ปัจจุบันได้ไม่ครบ
3. **ขอบเขต Export:** ไฟล์ 77 แถวมี 6 จังหวัดและไม่มี 8 จังหวัด Candidate จึงต้องตรวจ 16 ชื่อและ alias ในหน้า Admin สถานที่ก่อนสรุปว่าใหม่
4. **Landmark workflow:** importer ยังไม่รองรับ `place_key`, อันดับ, เหตุผล, `is_landmark`, `landmark_status`, source หลายรายการ หรือ image metadata
5. **รูป:** คงผลเดิม — full-size visual approved 0; ไม่อัปโหลดและไม่อ้างว่าพร้อมใช้
